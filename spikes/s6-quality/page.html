Streaming an environment

The stream goes straight from the node to the browser; the portal only brokers it. A browser needs a UDP path to the node: on the LAN that is direct, elsewhere it is a mesh such as Tailscale, a forwarded port, or a TURN relay. The player prefers webtransport where Chromium offers it and falls back to WebRTC everywhere else.

Note. Codec switches happen in place over WebTransport: the picture stays up until the first frame in the new codec, so a switch costs one or two frames at 60 fps.

Every frame of a hardware codec depends on the ones before it, so a lost datagram means the decoder shows garbage until the next keyframe. The page asks for one at once, and the streamer sends nothing that depends on a frame it could not send. PyroWave frames stand alone: a lost packet blurs its 32×32 block of one frame.

Shared GPUs. Image generation or an LLM on the same GPU delays every frame by up to one timeslice per GPU context it passes through. nvidia-smi compute-policy --set-timeslice=1 shortens it.

Input

  • Keyboard and mouse go up the control channel and into the compositor's seat.
  • Gamepads become virtual Xbox 360 controllers through /dev/uinput.
  • Held keys and buttons are released on blur, so nothing sticks.

/// Sends a frame, or drops it (and, for the hardware codecs, all until
/// a keyframe, which is asked for). True if sent.
fn send(
    &mut self,
    conn: &Connection,
    frame: &EncodedFrame,
    media: &Media,
    epoch: Instant,
    stats: &mut StreamerStats,
) -> bool {
    stats.frames_generated += 1;
    let intra = !frame.packets.is_empty();
    if self.resync && !frame.key && !intra {
        return false;
    }
    let sent = if intra {
        send_packets(conn, frame, self.frame_id, self.stream, epoch, stats)
    } else {
        send_frame(conn, &mut self.fragmenter, frame, self.frame_id, self.stream, epoch, stats)
    };
    if !sent {
        stats.frames_dropped += 1;
        media.request_keyframe(self.codec);
        return false;
    }
    true
}

  if (stream !== this.stream) {
    if (this.stream !== null && !newerStream(this.stream, stream)) return;
    this.startStream(stream, (v.getUint8(1) & FLAG_INTRA) !== 0);

}
