S1c codec compare

The same 1440p60 content as PyroWave (WebGPU decode) and as low-latency H.264 / HEVC / AV1 (WebCodecs, hardware preferred), replayed by the node over the same WebTransport path. Every frame is timed from the moment the server sent it: last fragment, decoded, drawn, handed to the compositor (canvas: the next animation frame; <video>: requestVideoFrameCallback's presentation time) and, for <video>, Chrome's expected display time.
